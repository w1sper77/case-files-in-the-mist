# 迷雾案卷 · Case Files in the Mist

一款移动端竖屏优先的悬疑推理游戏原型。玩家扮演私家侦探林彻，在暴雪封山的鹿鸣山庄调查《雪夜密室》，从现场痕迹、证词和时间线中拼出唯一真相。

## 当前版本

已实现第一章核心闭环：

- 案卷柜与四章案件预览
- 《雪夜密室》序章结果现场
- 书房、东回廊、厨房与客厅、高坤房间、人物检视
- 调查热点与证物检视
- 侦探手册：证物、人物、时间线、证词、推论
- NPC 询问与证据对峙
- 推理板线索组合
- 结案指认、作案环节排序、节点质证
- 可信度、直觉点、本地自动保存
- 桌面端与移动端响应式布局

第二至第四章目前以封存案卷形式展示，案件内容尚未接入。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可体验。

生产构建：

```bash
npm run build
```

## 技术栈

- React 18
- Vite 6
- lucide-react
- CSS 响应式布局
- localStorage 本地进度保存

## 视觉方向

采用原创的冷峻科幻调查界面：黑曜石背景、冰青信息高亮、暖金证据标记和档案式排版。视觉氛围参考现代科幻角色页面的高对比设计。

## 项目结构

```text
index.html        页面入口
src/main.jsx      游戏状态、案件数据与界面组件
src/style.css     视觉样式与响应式布局
```
